Architecture & Engineering Notes

Technical Field Notes & Deep-Dives

Architectural design patterns, protocol reverse-engineering findings, and high-performance server notes.

🔬
NOTE #01 · REVERSE ENG
541 Opcodes & 4,221 DTO Schemas

When reverse engineering the MU Origin 3 binary protocol, packet framing uses a 2-byte header delimiter followed by a 2-byte opcode identifier and length-prefixed payload. Using IL2CPP metadata dumps combined with live Wireshark dissection, 541 distinct protocol opcodes and 4,221 nested DTO structures were mapped into clean-room C++ and TypeScript schemas.

Opcode Disassembly IL2CPP Metadata Packet Serialization
⚡
NOTE #02 · GAME CORE
C++17 Non-Blocking Daemon Architecture

The `mu3-server` daemon core is architected around an asynchronous event loop with worker thread pools for compute-heavy combat calculations and MariaDB connection pooling. This decoupled architecture isolates database I/O latency from the 20ms game world tick loop, guaranteeing zero tick stutter under high player density.

C++17 Daemon Worker Pools MariaDB Pool Tick Loop
🌐
NOTE #03 · WEB & DEVOPS
Modern Web Routing & TLS 1.3 Architecture

All production platforms are engineered with modern reverse proxying, HTTP/2 multiplexing, automated TLS 1.3 cryptographic certificate renewal, and optimized socket pooling for high throughput and bulletproof web security.
